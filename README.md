# 一声就好 · astrbot_plugin_task_chime

Agent 跑完一轮任务，在你的电脑上响一声。

不是通知栏，不是弹窗，就是一声。你在别的窗口干活，听见了就知道那边收工了。

## 它做什么

- 监听一轮任务的结束时刻（v1.0.1 起挂在「消息已发出」之后，而不是模型一停就响）
- 只在耗时超过阈值的私聊里触发——一句话的事不值得响
- 带冷却，连续的任务不会变成连珠炮
- 找不到音效文件时回退系统提示音，不报错
- 非 Windows 宿主静默跳过，不阻塞消息

## 它不做什么

- 不发消息、不写数据库、不碰模型
- 不在群里响（群里一声提示音，等于吵所有人）
- 不改你的音频设备设置

## 安装

```text
放进 AstrBot 的 data/plugins 目录，重载插件即可。
```

要求 AstrBot ≥ 4.28.0，宿主为 Windows。

## 配置

配置项都在插件面板里：音效文件路径、触发阈值、冷却时间。留空就用默认值。

## 已知限制

- 只支持 Windows（其它平台静默跳过，这是刻意的，不是 bug）
- 音效文件必须是系统能直接播放的格式
- 任务很短时不响，这是设计，不是失灵
